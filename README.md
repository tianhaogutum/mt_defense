# Thesis Defense Presentation

Interactive HTML presentation for Tianhao Gu's TUM master's thesis defense.

## Run locally

Open `index.html` in a browser, or serve this folder with any static web server.
The presentation uses relative paths, so keep these files in their current locations:

- `presentation_final.html`
- `tum_logo.png`
- `llm_deployment_workflow.png`
- `llm_inference_engine_arc.png`
- `images/`

The `images/` directory contains the figures and tables used by the presentation.
The thesis PDF is also linked from several slides and should remain at the repository root:
`masterthesis_informatics_tianhaogu.pdf`.

## GitHub Pages

Set GitHub Pages to deploy from the repository's `main` branch and root directory.
The generated site will open through `index.html` and redirect to the presentation.
