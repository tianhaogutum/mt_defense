Overall Story
==================================================

The thesis studies a new fault localization problem:

Given:
- an issue report
- a pre-fix repository snapshot

Goal:

Identify the file that developers modify to fix the bug.

Constraints:

- No compilation
- No test execution
- No runtime traces
- Only issue report and repository


The thesis focuses on LLM inference engines because they are:

- large-scale systems software
- highly heterogeneous
- cross-layer
- difficult to debug


The research journey:

RQ1:
Can existing localization methods solve this problem?

RQ2:
What are the trade-offs between methods?

RQ3:
Why do LLM agents fail?

RQ4:
Can domain knowledge improve localization?
